# Security policy

## Supported versions

Security fixes are provided for the latest published release of Elo-MMR-Py.
Upgrade to that release before reporting an issue that may already be fixed.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/aropan/Elo-MMR-Py/security/advisories/new)
so the report, reproducer, and any proposed fix remain private until disclosure
is appropriate.

Include the affected package version, Python version, operating system, minimal
reproduction, expected impact, and whether the issue affects checkpoint files or
untrusted contest input. Do not include credentials or unrelated private data.

There is no guaranteed response-time SLA. Reports will be assessed according to
severity and maintainer availability. Please allow time to investigate before
public disclosure.
